# 功能调研笔记

本目录存放 JY文件管理器 的功能调研整理成果。

## 文件

- [`../FEATURES.md`](../FEATURES.md) — 完整功能矩阵（40+ 项，按模块分组），是开发任务的唯一权威清单
- [`../DEPENDENCIES-RESEARCH.md`](../DEPENDENCIES-RESEARCH.md) — pub.dev 可复用模块映射表，逐项标注「有现成包 / 需自研」

## 调研方法

功能矩阵按「文件管理核心 → 编辑器套件 → 压缩包 → 应用工具箱 → 系统与远程 → 高级能力」六个域整理，
每项功能都经过一轮「pub.dev 是否有成熟实现」的核实，结论写进依赖映射表。

## 开发原则

1. **能用现成包就不手写** —— 优先复用 pub.dev 上维护活跃、Dart 3 兼容的包
2. **只在无替代时自研** —— 主要是 Android 特有的二进制格式解析（AXML / ARSC / DEX）与 root / Shizuku 原生桥接
3. **自研部分独立成模块** —— 放在 `lib/core/` 下，不侵入 UI 层，便于单独测试与替换
